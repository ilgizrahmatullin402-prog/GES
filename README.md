# GES

Мини-приложение "Планировщик задачи".

Оно помогает разобрать большую задачу на понятные части:

- цель;
- материалы;
- первые шаги;
- риски;
- проверка результата.

Пока внутри нет настоящего ИИ. Приложение использует шаблон и позволяет вручную редактировать каждый блок.

## Как запустить

```bash
npm start
```

После запуска открыть:

```text
http://localhost:4173
```

## Проверка

```bash
npm test
```
